BEACON 2.8 — MOVIE SOURCE HUB

Update the SAME installed Beacon extension folder and click Reload at chrome://extensions. Back up the old folder first. Do not uninstall the extension, or the saved extension ID and settings may change.

CHANGED:
- Selecting Find sources now checks matching files already available in your TorBox/Premiumize libraries, alongside results from every enabled compatible streaming add-on.
- You can play an already-available cloud file directly from its title search, without navigating to the separate file list.
- Existing manual source selection, 1080p preference, provider directory, account persistence, and Live TV code retained.

LIMITATIONS:
- Syncler-only packages do not run in this extension.
- Cloud matching is filename-based; poorly named items or different title aliases may not match.
- No automatic guarantee for currently released commercial movies. You need an accessible licensed source, a compatible stream add-on, or media already in your connected cloud libraries.
- Browser codec support still applies.
