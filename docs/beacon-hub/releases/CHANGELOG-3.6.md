# Beacon 3.6 — Poster and episode metadata update

Based on the supplied Beacon 3.4 Chrome extension.

- Poster-first, keyboard-accessible media discovery.
- Exact-title results sorted ahead of similarly named prequels/spin-offs.
- Series details with season picker, episode thumbnails, air dates and synopses where catalog provides them.
- Episode identifiers use actual metadata or a valid ID fallback; no S01E00 queries.
- Preserves original Live TV, Express providers, TorBox, Premiumize, settings, history and playback code.

NOT INCLUDED: Native Windows portable EXE (source is a Chrome extension); Trakt OAuth/sync (requires app credentials and compliance review); guaranteed resume playback; providers beyond those installed.
