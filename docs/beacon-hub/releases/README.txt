BEACON FOR CHROME 1.0.0

INSTALL
1. Extract this ZIP to a normal folder. Do not delete that folder afterward.
2. In Chrome, open: chrome://extensions
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select the Beacon-Chrome-1.0.0 folder — the folder that directly contains manifest.json.
6. Pin Beacon from Chrome's Extensions menu if desired.
7. Click the Beacon toolbar icon. Beacon opens in a normal Chrome tab.
8. Turn on your VPN extension, then enter the IPTV server, username, and password in Beacon.

IMPORTANT
- Select the folder containing manifest.json, not the ZIP file and not a parent folder.
- Keep the extracted Beacon folder where it is. Chrome loads the extension from that folder.
- Beacon requests HTTP/HTTPS host access so it can connect directly to the IPTV provider from Chrome.
