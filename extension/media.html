Express package compatibility (29 provider rules) — click to expand

Import a publicly documented Syncler Express JSON package to inspect its provider rules. Compatible JSON rules and simple HTML selector rules can run independently. Complex expressions, tokens and scripts remain unsupported. Imported providers are disabled until you choose to enable them. Only use providers that permit automated access and content you are authorized to play.

Install a standard media add-on

Add an HTTPS Stremio-protocol add-on manifest URL. Compatible add-ons can supply catalogs and/or stream links. Stream-only providers are supported when a metadata catalog is installed. Existing Syncler vendor URLs are not supported here.

Official add-on directory

Browse the published Stremio official add-on index. A catalog can list titles without playable streams; a stream add-on may return external services instead of browser-playable video. Beacon never runs remotely supplied JavaScript.

Add vendor

Vendor manifests must use Beacon's declarative JSON format. Syncler manifests can be inspected but are not executable in Beacon.

You can also import a local Beacon vendor JSON file.

Playback preferences

Manual selection is always on. All sources stay visible; 1080p sources appear first when labeled. TorBox and Premiumize are both available without preference.

Trakt integration status

Trakt syncing is not connected in this release. Trakt requires a registered OAuth application and restricts integrations that promote copyright infringement. Beacon does not collect your Trakt credentials. For a compliant watch-history integration, review the Trakt developer requirements first.

Developer information: https://developer.trakt.tv/docs/create-an-app

TorBox

Provide the API token from your TorBox account settings. Used to list and play your accessible cloud files.

Premiumize

Enter your Premiumize API key. Cloud files are retrieved directly from Premiumize.

Backup and restore settings

Save vendors, installed add-ons, IPTV preferences/history, and playback options to a file. Account keys and IPTV login are included only in encrypted backups protected by your passphrase. Do not share backup files.

Import merges saved Beacon settings from the selected file into this extension. Importing overwrites matching settings. Refresh the app after importing.

Privacy

TorBox and Premiumize keys are saved in this Chrome profile until you disconnect or clear browser data. Chrome local storage is not encrypted by Beacon; only use on a trusted computer/profile. Encrypted backups are password protected. Links opened in a video element are subject to Chrome format and cross-origin restrictions.

Chrome may not play every codec or file type.
